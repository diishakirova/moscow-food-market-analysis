# Анализ рынка общественного питания Москвы для инвесторов

## О проекте
Проект посвящён исследовательскому анализу рынка общественного питания Москвы.  
Цель работы — помочь инвесторам определить перспективные форматы заведений, районы для открытия и стратегию выхода на рынок.

Проект выполнен в рамках обучения аналитике данных.

---

## Бизнес-задача
Инвесторам необходимо понять:
- какие форматы заведений наиболее востребованы;
- какие районы Москвы наиболее перспективны;
- какие факторы влияют на рейтинг заведений;
- какие параметры учитывать при запуске нового бизнеса.

---

## Цели исследования
- изучить структуру рынка общественного питания Москвы;
- проанализировать распределение заведений по категориям и районам;
- исследовать рейтинги заведений и факторы, влияющие на них;
- сравнить сетевые и несетевые заведения;
- определить ключевые характеристики успешных заведений;
- сформулировать рекомендации для инвесторов.

---

## Используемые данные

### Основной датасет: `rest_info.csv`
Содержит информацию о заведениях:
- название;
- адрес;
- административный район;
- категория заведения;
- часы работы;
- рейтинг;
- признак сетевого заведения;
- количество посадочных мест.

### Дополнительный датасет: `rest_price.csv`
Содержит информацию о ценах:
- категория цен;
- средний чек;
- медианная стоимость заказа;
- стоимость капучино.

---

## Этапы работы

### 1. Загрузка и знакомство с данными
- изучение структуры датасетов;
- проверка типов данных;
- выявление пропусков.

### 2. Предобработка данных
- очистка данных;
- обработка пропусков;
- преобразование типов;
- создание новых признаков.

### 3. Исследовательский анализ
- анализ категорий заведений;
- распределение заведений по районам Москвы;
- анализ рейтингов;
- сравнение сетевых и несетевых заведений;
- анализ вместимости заведений;
- исследование ценового сегмента.

### 4. Формирование выводов
- выявление закономерностей;
- определение перспективных сегментов;
- рекомендации для инвесторов.

## Результаты исследования
В ходе анализа:
- определены наиболее популярные категории заведений;
- выявлены районы с высокой концентрацией бизнеса и потенциалом роста;
- определены факторы, влияющие на рейтинг;
- выявлены различия между сетевыми и несетевыми заведениями;
